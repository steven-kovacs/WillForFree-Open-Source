Reddit Sans (SIL OFL, see OFL.txt) is the source typeface. The original web subsets are retained for reproducibility. On November 13, 2026, the supplied screenshot showed hollow intersections in the A on the original variable font. For the WillForFree static subsets, instantiate weight 400, 500, 700 or 900 with fontTools.varLib.instancer.instantiateVariableFont, union overlaps throughout glyf using fontTools.ttLib.removeOverlaps.removeOverlaps, set internal family and unique IDs to WillForFree Sans, and save WOFF2. The two static PDF fonts use the full Latin/extended source TTF from the Google Fonts Reddit Sans distribution, the same outline operations at 400/700, and TTF output. Preserve the copyright and license in every distribution.

The extended document font uses the Google Fonts Noto Sans SC variable TTF at weight 450. Missing Latin and punctuation glyphs are copied from wff-pdf-regular.v2.ttf with the outline coordinates scaled to the new units per em. The resulting family is WillForFree Document Sans. The original sources and both SIL OFL notices are included by reference in the third-party notices. Set the merged TrueType glyf table’s padding to 2 with fontTools before saving. The bundled PDF subsetter uses two-byte glyph offsets in small subsets. All document builds request the same font assets. The browser selects the appropriate outlines privately and embeds the glyphs in the PDF.
